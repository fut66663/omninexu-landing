Data Sources & Coverage

Every data point traceable to its SEC origin.

SEC EDGAR

Direct from sec.gov. 10-K (annual), 10-Q (quarterly), Form 4 (insider), 13F (institutional). Parsed via edgartools.

  • 500 S&P 500 constituents
  • Annual + quarterly data

SimFin

Standardized financial statements for ~4,700 US-listed companies. Bulk historical data FY2020–present via local CSV cache.

  • Annual + quarterly variants
  • Banks & non-banks handled separately

Cross-Validated

SimFin vs EDGAR cross-source comparison. Discrepancies >2% flagged as warning, >10% as critical. Agents can trace any data point to the source filing.

  • 9 core concepts compared
  • CIK + accession number traceable
